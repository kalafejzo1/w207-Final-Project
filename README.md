# LA Airbnb Revenue Prediction

Predicting estimated annual revenue for Airbnb listings across Los Angeles neighborhoods, combining Airbnb listing data with Zillow housing data for neighborhood-level context.

We built a full preprocessing and feature engineering pipeline, then compared several modeling approaches — linear regression, random forest, gradient boosting, and manually tuned neural networks — evaluated on MAE, RMSE, and R².

Team final project for UC Berkeley's DATASCI W207 (Summer 2026), with Kevin, Hubert, and Kala.

## Contents

- `notebooks/` — individual and combined modeling notebooks (preprocessing, feature engineering, model comparison)
- `data/` — Airbnb LA listings, Zillow neighborhood data, and the cleaned/merged modeling dataset
